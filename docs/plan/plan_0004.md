# GPUWatcher Phase 3 Overview Console 리팩토링 계획

## TL;DR

Phase 3는 현재 Overview 화면을 Phase 1 shell과 Phase 2 디자인 시스템 위에서 절제된 GPUWatcher 전용 dark desktop console로 정리하는 작업이다.

핵심은 새 backend 기능이 아니라 현재 `ServerOverviewDto`만으로 정보 계층을 개선하는 것이다. fleet summary를 추가하고, 서버 카드를 낮은 깊이의 compact console row로 바꾸며, 기존 검색/필터/refresh/seed/diagnostic/query invalidation 동작은 유지한다.

작업은 TDD 우선으로 진행한다. 먼저 summary pure function 테스트와 Overview behavior 테스트를 추가한 뒤 구현한다. Rust, DB, Electron, preload, helper, scheduler, API, DTO, query key, Zustand, browser fallback은 절대 변경하지 않는다.

## 현재 기준선

| 영역 | 현재 상태 |
| --- | --- |
| Phase 2 계약 | `docs/plan/plan_0003.md`가 binding design contract다. Phase 1/2 shell과 디자인 시스템을 되돌리지 않는다. |
| `OverviewScreen.tsx` | `Button`, `InlineToolbar`, `LabeledTextInput`, `LabeledSelect`, `ResetButton`, `ResultFeedback`, `LoadingState`, `ErrorState`, `EmptyState`를 이미 사용한다. |

## 제품/설계 결정

### Fleet summary semantics

`overviewModel.ts`에 현재 DTO만 사용하는 pure helper를 둔다.

| 값 | 정의 |
| --- | --- |
| Total servers | `overview.length` |
| Online servers | `server.status.toLowerCase() === 'online'`인 서버 수. exact case-insensitive equality만 허용 |
| Needs attention | status가 `stale`, `error`, `failed`, `degraded` 중 하나를 포함하거나 `lastErrorType`/`lastErrorMessage`가 존재하는 서버 수 |
| Total GPUs | `gpuTotal` 합계 |
| Busy GPUs | `busyGpuCount` 합계 |
| Free GPUs | `freeGpuCount` 합계 |

`needs attention`은 `non-online`과 같지 않다. `stale`은 attention에는 포함되지만 error로 합쳐지지 않는다. 기존 stale/error quick filter semantics는 유지한다.

### 화면 구조

```text
Plain page header
Fleet summary strip
Filter toolbar
Loading / error / result feedback
Server list
Empty state
```

Page header는 rounded panel이 아니다. Loading, backend error, no configured servers, filtered empty 상태에서도 Overview identity는 유지한다.

### Fleet summary UI

모든 summary metric을 별도 큰 card로 만들지 않는다. 하나의 compact strip/surface로 표시한다.

예시:

```text
Servers        Online        Needs attention        GPUs
5              3             2                      12 total · 8 busy · 4 free
```

서버가 없을 때는 fake health number를 만들지 않는다. 필요하면 `0 servers`만 명확히 보여주고 no configured servers empty state를 우선한다.

### Filter toolbar

기존 기능을 모두 유지한다.

| 기능 | 보존 |
| --- | --- |
| Search | name, host, status, error type, sanitized error message 검색 |
| Status | 현재 overview rows에서 option 생성 |
| Quick filter | `all`, `stale`, `error` 유지 |
| Reset | 테스트 없이 disabled 동작을 새로 요구하지 않는다. 기존 always-enabled reset 유지 가능 |
| Summary | `Showing N of M servers` 유지 |
| State | filter state는 `useOverviewController`가 계속 소유 |

### Server row/card

현재 8개 nested `MetricCard` 구조를 compact console row로 바꾼다.

```text
Server name + status        Last successful poll        Refresh
host

GPU total    Busy / free    GPU util    Memory    Max temp
4            3 / 1          81.2%       70.0%     74.0 C

Diagnostic summary only when needed
```

| 항목 | 결정 |
| --- | --- |
| Detail navigation | server identity button만 detail로 이동 |
| Whole card button | 금지 |
| Refresh | 별도 button, accessible name에 server name 포함 |
| Last success | metric cell이 아니라 header metadata |
| Error type/message | 일반 metric cell 금지. diagnostic 영역에서만 표시 |
| Diagnostics | `lastErrorType` 또는 `lastErrorMessage`가 있을 때만 표시 |
| Redaction | 기존 `DiagnosticPanel`, `sanitizeMessage`, guidance 유지 |
| Healthy server | 빈 diagnostic 공간을 남기지 않음 |

### CSS / 접근성

새 class는 `.overview-*` prefix를 사용한다. 예: `.overview-page`, `.overview-header`, `.overview-summary`, `.overview-server-row`, `.overview-server-metrics`, `.overview-server-diagnostic`.

| 항목 | 기준 |
| --- | --- |
| Visual language | Phase 2 token 기반, low-contrast border, restrained dark console |
| 금지 스타일 | brand clone, glow, glass, excessive gradient, excessive pill, hover movement |
| Density | full/compact 모두 유지 |
| Responsive | 최소 창에서 horizontal overflow 방지 |
| 긴 문자열 | server name, host, error message wrap/break 처리 |
| Accessibility | heading hierarchy, visible focus, status text, live region, alert semantics, keyboard flow 유지 |

### Visual/accessibility QA matrix

| 상태 | 확인 |
| --- | --- |
| multi-server full density | header, summary, toolbar, rows, diagnostics, actions가 Phase 2 문법과 일치 |
| multi-server compact density | content 유지, spacing만 안전하게 축소 |
| online only | needs attention이 error처럼 보이지 않고 diagnostic 없음 |
| stale/error mixed | stale과 error가 시각적으로 구분되고 둘 다 attention에 포함 |
| null metrics | `unknown` 표시, 0으로 변환 없음 |
| long names/host/errors | wrap/break 처리, horizontal overflow 없음 |
| loading | header 유지, fake number 없음 |
| backend error | header 유지, sanitized error 표시 |
| no configured servers | filtered empty와 구분 |
| filtered empty | reset action 동작 |
| refresh pending | row identity/metrics 유지, pending feedback 연결 |
| refresh success | filters 유지, compact success feedback |
| refresh failure | server-local error feedback, redaction 유지 |
| minimum window | critical clipping 없음 |
| keyboard/focus | search/select/reset/identity/seed/refresh focus와 accessible name 확인 |

Electron visual QA가 우선이다.

```bash
npm run dev
```

| 항목 | 기록 내용 |
| --- | --- |
| Blocker | Electron QA가 불가능한 이유 |

| Risk | 남은 Electron-only visual/runtime risk |

## 완료 기준

- Overview가 Phase 1/2 shell과 자연스럽게 연결되는 restrained GPUWatcher dark desktop console로 보인다.
- Fleet summary가 total, online, needs attention, GPU capacity를 즉시 보여준다.
- Online과 needs-attention semantics가 이 문서 정의와 테스트에 고정된다.
- Stale은 error로 합쳐지지 않는다.
- Server row 깊이와 높이가 줄고, core metrics가 빠르게 읽힌다.
- Last success는 metadata로 이동한다.
- Error type/message는 diagnostic 영역에서만 보인다.
- Healthy server에는 diagnostic 빈 공간이 없다.
- 기존 Overview 13개 behavior 영역이 유지되고 새 테스트가 추가된다.
- Backend/Rust/DB/Electron/preload/helper/scheduler/API/DTO/query key/Zustand/browser fallback 변경이 없다.
- `null`, `unknown`, `N/A`, missing 값을 0으로 바꾸지 않는다.
- `.overview-*` scoped CSS를 사용한다.
- 자동 검증과 visual/accessibility QA evidence가 기록된다.
- 명시 요청 전 commit/push가 없다.

## 커밋 정책

명시적으로 요청받기 전에는 commit/push하지 않는다.

나중에 commit 요청이 있으면 다음 atomic commit 순서를 사용한다.

| Commit | Scope |
| --- | --- |
| `test(overview): lock fleet summary and overview behavior` | `overviewModel.test.ts`, `OverviewScreen.test.tsx` |
| `feat(overview): add fleet summary helpers` | `overviewModel.ts` pure helper |
| `refactor(overview): restructure overview console screen` | `OverviewScreen.tsx`, `OverviewServerCard.tsx` |
| `style(overview): add scoped responsive console styles` | `src/styles/screens.css`와 className wiring |
| `test(overview): finalize regression coverage` | 구현 후 필요한 test adjustment만 |

각 commit 전 focused test를 통과시킨다. 최종 commit 전에는 아래를 통과시킨다.

```bash
npm run test -- --run
npm run build
npm run electron:build
```

Commit message body에는 정확히 다음 attribution을 포함한다.

```text
Ultraworked with [Sisyphus](https://github.com/code-yeongyu/oh-my-openagent)

Co-authored-by: Sisyphus <clio-agent@sisyphuslabs.ai>
```
