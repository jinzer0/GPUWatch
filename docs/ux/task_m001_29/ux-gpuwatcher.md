2026-10-05 설계 최종화 승인을 반영했다. 개별 확정하지 않은 세부는 `[ASSUMPTION]` 잠정 구현 기준으로 구분한다. 브라우저 시안에는 예시 데이터만 사용하며 제품 코드 구현 승인이나 실제 앱 검증 결과가 아니다.

기존 서버 관리는 유지한다. 서버별 `…` 메뉴에 편집·삭제·모니터링 켜기/끄기·SSH 연결 테스트, 사이드바 `+` 메뉴에 서버 직접 추가·SSH config 가져오기를 배치한다.

가용 알림은 펼친 GPU 카드에 둔다. UTIL ≤5% 및 VRAM ≤1GiB가 5분 지속되면 카드에 `사용 가능`을 표시하고, 알림을 켠 경우 macOS 알림을 제공한다. 유휴 지속 중에는 반복하지 않으며 재사용 후 가용 재충족·최소 15분 간격을 적용한다. 실패·unknown·stale은 현재 가용으로 판정하지 않는다.

기존 GPU 상세 지표는 삭제하지 않고 각 카드 안의 기본 접힘 `추가 지표`로 보존한다. 메모리 활동률·남은 VRAM·전력·팬, 기능·식별·클록, PCIe·MIG 정보를 포함한다. 요약 지표와 프로세스 표는 기존 위치를 유지하고 History 차트는 복원하지 않는다.

현재 HTML 시안은 예시 데이터 기반 검토용이다. 라이트·다크의 서버별 `…`와 `+`, GPU 카드와 내부 `추가 지표`는 HTML 기본 펼침으로 배치를 확인할 수 있다. 별도 서버 관리 시안은 편집 시트·삭제 확인·모니터링 꺼짐·SSH 테스트 결과·가져오기 미리보기와 실패 예시를 담는다. GPU 3 안에는 OS 알림 설정 확인 안내, 앱 모형 밖에는 사용자 지정 조건·저장 실패·읽기 실패 예시를 추가했다. 서버 조작·저장·SSH 접속은 실행하지 않는다.

## 잠정 인계 범위

사용자의 비용·시간 효율 지시에 따라 되돌리기 쉬운 세부는 반복 질문 없이 `[ASSUMPTION]`으로 유지한다. PID·사용자·명령·VRAM 표, 현재 토큰·밀도, 최초 시스템 테마, 마지막 서버와 세션 내 펼침 복원, 변경 버리기 확인을 잠정안으로 삼는다. 기존 알림 조건의 읽기·보존과 새 임계값 편집기 제외는 수용된 이번 인계 범위이며 편집기 추가 여부를 이번 최종화의 미결정 항목으로 두지 않는다.

| 표면 | 현재 근거 |
|---|---|
| 메인·GPU 추가 지표·서버 메뉴 | 라이트·다크 시안 |
| 설정 외형 선택 | 별도 설정 창 시안 |
| 서버 편집·삭제·테스트·가져오기 | 서버 관리 시안 |
| 알림 조건·권한 확인 불가·실패 | 메인 시안의 GPU 3 및 대체 상태 |
| 최초 로딩·서버 없음/미선택·GPU 없음·성공 스냅샷 없는 연결 실패·프로세스 수집 불가 | EXPERIENCE 상태 계약으로 인계; 추가 시안 생략 승인 |
| 신규 서버 빈 입력·저장 중·모니터링 변경 실패·설정 로딩/저장 실패 | EXPERIENCE 상태 계약만 있음; 편집·설정 시안이 모든 상태를 표현하지는 않음 |
| 변경 버리기 확인·포커스 복원·실제 창/테마 전환·OS 알림 통합 | EXPERIENCE 행동 계약만 있음; HTML 기본 펼침과 정적 알림 예시가 구현 증거는 아님 |

두 계약을 final로 전환하고 4개 시안을 `mockups/`로 승격했다. 사용자가 승인한 비용 최소화 안에 따라 선택 UX 검토는 생략하고 위 계약 전용 표면은 추가 시안 없이 인계한다. 기록·시안 대조와 문서 정제·정적 검증은 선택 UX 검토나 실제 앱 검증과 구별한다. `imports/`는 비어 있어 별도 입력 대조 대상은 없다. 제품 구현은 별도 Issue·계획·승인 대상이다. 현재 코드의 알림 재활성화 시 조건 초기화, 규칙 변경 시 반복 방지 상태 초기화, OS 권한 상태 미노출은 구현 인계 주의사항으로 남긴다.
