# Task #19 수행계획서 — Task: Shell 내비게이션과 상단 툴바 디자인 리팩토링

GitHub Issue: [#19](https://github.com/jinzer0/GPUWatch/issues/19)
마일스톤: M001

## 목적

GPUWatcher의 Shell, Sidebar, 상단 titlebar/toolbar를 macOS용 GPU Activity Monitor 방향에 맞게 정리한다. Overview와 Process Table 병렬 리팩토링이 독립적으로 진행될 수 있도록 화면 껍데기와 전역 내비게이션 책임만 다룬다.

## 배경

현재 Shell은 좌측 sidebar와 titlebar를 제공하지만 화면 명칭과 상태 정보가 서버/GPU 작업 흐름 중심으로 충분히 정돈되어 있지 않다. 디자인 후보 조사 결과, GPUWatcher에는 Apple HIG의 macOS sidebar/toolbar 구조와 Linear/Raycast식 빠른 내비게이션을 결합한 방향이 적합하다.

## 범위

### 포함

- `src/components/Shell.tsx`의 sidebar IA, label, active state 정리
- `src/styles/layout.css` 중심 Shell/titlebar/sidebar 스타일 보정
- `src/components/Shell.test.tsx` 갱신
- fleet status와 backend/refresh 상태를 표현할 수 있는 toolbar 구조 정리

### 제외

- Overview dashboard KPI/카드 내용 개편
- Process Table 화면 구조 개편
- Electron/Rust backend/helper contract 변경
- 원격 명령 또는 destructive action 추가

## 설계 방향

- Sidebar는 GPUWatcher의 주요 작업 흐름을 기준으로 짧고 얕게 유지한다.
- 상단 영역은 현재 화면명, fleet 요약, backend/refresh 상태를 분리해 읽히도록 한다.
- 기존 `contextIsolation`, renderer API 경계, density control 동작은 변경하지 않는다.
- Tailwind 유틸리티와 기존 CSS token을 섞는 현재 패턴을 따르되 새로운 디자인 token 남발은 피한다.

## 리스크

- **병렬 변경 충돌**: Overview/Process 작업과 공통 Shell API가 충돌하지 않도록 Shell props 변경을 최소화한다.
