# Task #20 수행계획서 — Task: Overview를 GPU Activity dashboard로 전환

GitHub Issue: [#20](https://github.com/jinzer0/GPUWatch/issues/20)
마일스톤: M001

## 목적

Overview를 서버 목록 중심의 Fleet snapshot에서 GPU Activity dashboard 첫 화면으로 전환한다. 현재 DTO에서 계산 가능한 GPU/프로세스/주의 상태를 우선 배치해 사용자가 GPU 사용 현황을 즉시 파악하게 한다.

## 배경

디자인 후보 조사 결과 GPUWatcher는 macOS용 GPU Activity Monitor 방향이 적합하다. 현재 Overview는 서버 수와 온라인 상태를 요약하지만 GPU 모니터링 앱의 첫 질문인 GPU가 얼마나 바쁘고 어떤 호스트에 주의가 필요한지에 대한 시각 계층이 약하다.

## 범위

### 포함

- `src/features/overview/*`의 summary/model/screen/card 표현 갱신
- `src/styles/screens.css`의 Overview dashboard 레이아웃 보정
- Overview 관련 테스트 갱신
- loading/error/empty/filtered-empty 상태 유지

### 제외

- Shell navigation/toolbar 변경
- Process Table 핵심 화면 구조 변경
- 신규 backend metric, DCGM, Prometheus 연동
- 설정 가능한 dashboard builder 추가

## 설계 방향

- GPU 상태, busy/free GPU, active process, attention host를 서버 수보다 먼저 읽히게 한다.
- 현재 `ServerOverviewDto`에서 계산 가능한 값만 사용하고 unknown/null 의미를 보존한다.
- 카드 수를 늘리기보다 KPI row와 서버 카드의 정보 계층을 재정렬한다.
- seed demo data와 plain Vite/backend unavailable 흐름은 유지한다.
