# `working/` 폴더 규칙

## 목적

각 Stage의 상태·Evidence·다음 실행 컨텍스트를 기록한다. Scope 내 다음 단계는 자동 진행한다. 승인 판단은 [`공통 정책`](../manual/agent_code_hyperfall_rule_conflict.md)을 따른다.

## 답하는 질문

- "어디까지 했는가?"
- "검증은 통과했는가?"
- "다음 단계에 어떤 영향을 주는가?"

## 작성 시점

한 Stage 구현과 검증이 끝난 직후, 다음 Stage로 넘어가기 전.

## 허용 파일명

`task_{milestone_slug}_{이슈번호}_stage{N}.md`

## 사용 템플릿

`mydocs/_templates/stage_report.md`

## 반드시 포함할 내용

- 단계 목적
- 산출물
- 본문 변경 정도 또는 무손실 여부
- 검증 결과
- 잔여 위험
- 다음 단계 영향
- 위험 결정과 승인 기록(해당할 때만)

## 두면 안 되는 내용

- 최종 결과보고서
- 아직 검증 실패인 단계의 완료 선언
- 허용된 Scope 밖 구현 계획의 무단 변경

## 다음 세션 AI가 복원해야 할 맥락

마지막으로 검증된 단계, 실패/차단 상태, 남은 위험, 다음 단계에서 이어받을 조건.
